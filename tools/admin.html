الاتصال بـ GitHub

الصفحة دي بتقرا بيانات الأكواد من الريبو وتنشر التغييرات عليه مباشرة. محتاجة GitHub Token بصلاحية على ريبو lamma-car.github.io بس.

إزاي تعمل Token (مرة واحدة):
  1. GitHub ← صورتك ← Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token.
  2. Resource owner: Lamma-Car · Repository access: Only select repositories ← lamma-car.github.io.
  3. Permissions ← Repository permissions ← Contents: Read and write. (مافيش أي صلاحية تانية مطلوبة.)
  4. Generate، وانسخ الـ Token والصقه هنا. ماتحطّوش في أي ملف ولا تبعته لحد.
